# A股盯盘助手（安卓 / HarmonyOS 4）

每 10 分钟自动抓取东方财富涨停池与炸板池，在本地累积 25 个交易日节点，无需电脑常开、无需服务器、无需谷歌服务。

## 功能

- 交易日 9:40–11:30、13:00–15:00，每 10 分钟自动抓取一次
- 25 个节点时间线：涨停家数、炸板家数、较上一节点增量、最强板块、最高连板
- 数据存在手机本地，关掉 App 再打开仍可查看当天历史节点
- 常驻通知显示服务运行状态，不依赖 Google Play 服务
- 下拉或点右上角按钮可手动抓取当前节点

## 安装（WIKO Hi 畅享 70 Pro / BAL-AN20 / HarmonyOS 4）

1. 到本仓库 Releases 下载 `app-release.apk`，传到手机。
2. 如提示禁止安装：进入「设置 → 系统和更新 → 纯净模式」，选择「退出纯净模式」；再在弹窗中允许此次安装。
3. 首次打开 App 时，允许「通知」权限和「忽略电池优化」请求。
4. 在「设置 → 应用 → 应用启动管理」中找到本 App，关闭「自动管理」，手动打开「允许自启动、允许关联启动、允许后台活动」。这一步不做，锁屏后服务可能被系统停掉。
5. 首页显示"后台自动抓取已开启"即正常；每个整十分钟会自动记录一个节点。

## 数据来源

东方财富公开接口 `push2ex.eastmoney.com` 的 `getTopicZTPool` / `getTopicZBPool`，与网页版一致，无需 API Key。

## 目录说明

- `lib/` — Flutter 源码
- `android/app/src/main/AndroidManifest.xml` — 权限与前台服务声明
- `.github/workflows/build_apk.yml` — 云端自动构建 APK 并发布到 Releases
- `web/` — PWA 网页版备份（适合不支持 APK 的设备，功能相同但没有可靠后台更新）
